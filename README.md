# ECサイト購買ファネル分析

## 1. 背景と目的

商品を閲覧した訪問者のうち、購入に至るのは約0.8%にとどまる。施策の対象を絞るため、ファネルの離脱箇所と離脱が多い条件を特定し、その差が他の条件や訪問者の違いを除いても残るかを確認したうえで、施策の優先順位を整理した。分析の問いは次の3点である。

1. 購買ファネルの最大の離脱はどの段階か。カート追加後の行動はどの程度の時間で終わるか。
2. カート追加後の購入率は、どの条件で低いか。その差は他の条件や訪問者の違いを除いても残るか。
3. 商品の在庫状態は、ファネルのどの段階に影響するか。

## 2. 結論

- **最も離脱が大きいのは「閲覧→カート追加」の段階である。** 訪問者の約7割は期間中のイベントが1件のみであり、カート追加に進むのは2.7%、購入に至るのは0.8%である。
- **カート追加後の行動の大半は30分以内に記録される。** 放棄されたカートが後から同一商品で購入される割合は0.7%と小さい。
- **カート追加後の購入率は、条件(時間帯・曜日・同時に追加した商品数・商品の人気度・閲覧の有無)によって差がある。** ただし、時間帯・曜日の差は、訪問者の構成の違いを反映している可能性がある。
- **在庫なしの影響は「閲覧→カート追加」の段階に現れ、カート追加後の購入率には現れない。**
- **417人の高頻度アクセス訪問者が購入の約29%を占める。** 一般訪問者とは行動が大きく異なるため、別に扱う必要がある。

## 3. 提案

6件の施策に、①根拠の確からしさ(比較を絞っても差が残るか)、②規模・効果の目安(購入数への影響)、③着手の前提(追加の確認やデータ整備が不要か)の順に優先して、1〜6の順位を付けた。

| 順位 | 施策 | 根拠 | 効果の目安 |
|---|---|---|---|
| 1 | 在庫変動商品の在庫なし期間に、在庫のある代替商品を提示する(在庫なし表示の見直しを含む) | 同一商品内、同一訪問者内でも、在庫なし期間は閲覧→カート追加率が低い | カート追加が1.3〜5.1%、購入が0.9〜3.8%増える試算 |
| 2 | カテゴリ250・1490・1600・1482のカート追加後の導線を、購入率の高いカテゴリ1224と比較して改善する | 4カテゴリは、カート追加後の購入率の信頼区間の上限が全体平均を下回る | 購入が約4.1%増える試算 |
| 3 | 同時にカートへ入れた商品が多い訪問者向けに、カート内の比較・絞り込みを支援する | 同時にカート追加した商品数が5件以上だと購入率が低く、同一訪問者内でも差が残った | 購入が約4.0%増える試算 |
| 4 | カート追加後30分程度の導線を改善する(決済画面の入力負担の軽減、離脱時の声かけ) | 購入の約8割が30分以内に起きる | 推定できない |
| 5 | 高頻度アクセス訪問者を別のセグメントとして扱う(一般訪問者向け施策の効果測定から除外する) | 417人が購入の約3割を占める | 推定していない |
| 6 | 常時在庫なしの商品ページを整理する(非表示、販売終了の案内、類似商品への誘導) | 最初の閲覧の後に離れる割合が高い(商品の違いは未調整) | 推定できない |

順位は効果の大きさの順ではない。効果の目安は分析データ上の試算であり、実施前にABテスト等で検証する。在庫に関する施策(1位、6位)は、在庫フラグの意味の確認が前提である。各施策の留意点は、`docs/analysis_report.md` の4章を参照。

## 4. データと分析手法

Retailrocket 社が公開している E コマースデータセット(Kaggle: `retailrocket/ecommerce-dataset`)を使用した。利用条件は Kaggle の配布ページを参照。元データはリポジトリに含めていない。

- **対象**: 期間は2015年5月3日〜9月18日(UTC)、行動ログは約276万件(重複除去後)、訪問者は約141万人である。データは匿名化されており、商品名・価格・カテゴリ名は含まれない。
- **分析の流れ**: SQL(DuckDB)で「訪問者×商品」単位のテーブルを構築して集計し、Python で信頼区間の計算、回帰、図表作成を行った。主要な数値は、SQL とは別に pandas のみで再計算して検証した。
- **主な判断**:
  - 閲覧またはカート追加を起点に、起点から7日以内の行動を追跡した。
  - 期間中のイベントが100件以上の訪問者(417人)は購入の約3割を占め、行動が大きく異なるため「高頻度アクセス訪問者」として分離した。結果は断りがない限り一般訪問者のものである。
  - 条件間の差は、単純比較のあと、同一商品内・同一訪問者内の比較とロジスティック回帰で、他の要因を除いても残るかを確認した。信頼区間は訪問者単位のブートストラップで求めた。

## 5. 限界

比較はいずれも観察データに基づく関連であり、因果効果ではない。在庫フラグは約1週間間隔のスナップショットで、イベント時点の状態とずれている可能性がある。価格・売上のデータがなく、効果は購入件数でのみ評価している。詳細は `docs/analysis_report.md` の5章を参照。

## 付録:主な用語・指標

| 用語・指標 | 説明 |
|---|---|
| 訪問者×商品 | 同じ訪問者が同じ商品に対して行った一連の行動のまとめ。本分析のファネルの単位 |
| 追跡期間 | 起点(訪問者×商品ごとの初回の閲覧、または初回のカート追加)から行動を観察する期間。本分析では7日 |
| 閲覧→カート追加率 | 閲覧した組のうち、追跡期間内に同一商品をカートに追加した組の割合 |
| カート追加→購入率 | カートに追加した組のうち、追跡期間内に同一商品を購入した組の割合(「カート追加後の購入率」とも記す) |
| 閲覧なしのカート追加 | ログ上、カート追加より前に同一商品の閲覧がないカート追加 |
| 高頻度アクセス訪問者 | 期間中のイベントが100件以上の訪問者。一般訪問者と行動が大きく異なるため分離した |
| 在庫フラグ | 商品属性 `available`。1が在庫あり、0が在庫なし。約1週間間隔で記録される |
| 商品内比較 / 訪問者内比較 | 同一商品の中、または同一訪問者の中で条件を比べる方法。商品や訪問者の違いによる影響を除く |
| 95%信頼区間 | 同じ手順でデータを取り直して区間を繰り返し作ると、その95%が真の値を含むように設計された区間。訪問者単位のブートストラップで算出 |

そのほかの用語は `docs/analysis_report.md` の付録Aを参照。
